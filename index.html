    S3-FIFO

    Simple and Scalable caching with three Static FIFO queues

    Most objects in a cache are never requested again. S3-FIFO lets them go soon after they arrive, so the space goes to objects that are reused, and a hit only bumps a two-bit counter, with no lock.

    How it works

    Filter new objects first, then keep the ones that are reused

    New objects wait in a small queue. Most are never requested again and leave quickly. Objects that are reused move on to the main queue, which keeps them for as long as they keep getting hits.

    1. S

      New objects start small

      S holds about 10% of the cache. An object hit twice while in S moves to M; the rest are evicted as soon as S needs room. This is quick demotion.

    2. G

      Evicted keys are remembered

      G keeps only the keys of objects evicted from S, as many as M holds. A key requested again while it is in G goes straight into M.

    3. M

      Reused objects go around again

      When M needs room, it checks its oldest object: with a counter above zero, it is reinserted with the counter lowered by one (lazy promotion); otherwise it is evicted.

    4. 2 bits

      Hits touch two bits

      A hit increments a counter capped at 3 with one atomic update. Nothing moves and nothing locks on the hot path, so S3-FIFO scales with threads.

    Why it works

    Most objects are never reused

    Cache workloads are skewed, and a cache only ever sees a short stretch of requests. In that stretch, most objects are requested once: with a cache at 10% of a trace’s footprint, about 72% of objects are not reused before they are evicted.

    LRU keeps each of these one-hit wonders for a full trip through the queue. S3-FIFO’s small queue lets them go after a short stay, which leaves the main queue to the objects that earn their place.

    Use it

    Try it in a few lines

    Experiment with the Python package, pick a production library in your language, or replay your own traces in libCacheSim.

    example.py
    $ pip install cachemonCache 
    from cachemonCache import S3FIFO

# A cache that holds up to 1,000 objects
cache = S3FIFO(cache_size=1000)

# Add an object; it expires after 60 seconds
cache.put("key", "value", ttl_sec=60)

# Look it up
print(cache.get("key"))   # value
print("key" in cache)     # True

# Remove it
cache.delete("key")
print(cache.get("key"))   # None

# It also behaves like a dict
cache["answer"] = 42
print(cache["answer"])    # 42
